# Data Visualization | CodeAlpha Data Analytics Internship

## Problem Statement -
The objective of this project is to transform raw sales data into meaningful visualizations using Python. The goal is to analyze business performance, identify trends and patterns, compare different business metrics and present insights through clear and informative charts that support data driven decision making.

## Tools Used -
1. Python
2. Jupyter Notebook
3. Pandas 
4. Matplotlib 

## Project Workflow -
1. Imported the required Python libraries.
2. Loaded the Superstore Sales dataset into a Pandas DataFrame.
3. Explored the dataset using summary statistics and information functions.
5. Cleaned the dataset by checking missing values, duplicates and correcting data types.
6. Performed exploratory data analysis (EDA) to understand the data.
7. Created multiple visualizations including bar charts, pie charts, line charts, histograms and scatter plots.
8. Analyzed sales, profit, customer segments, regions, product categories and monthly sales trends.
9. Interpreted each visualization to identify business insights and patterns.
10. Summarized the key findings and provided business recommendations based on the analysis.
