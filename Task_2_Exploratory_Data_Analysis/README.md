# Exploratory Data Analysis of Hotel Booking Data | CodeAlpha Data Analytics Internship

## Problem Statement -
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Hotel Booking dataset. Through this analysis, we aim to understand the structure of the data, identify trends and patterns, detect data quality issues, test assumptions using statistics and visualizations and generate meaningful business insights.

## Tools Used -
1. Python
2. Jupyter Notebook
3. Pandas
4. Matplotlib
5. Seaborn 

## Project Workflow -
1. Imported the required Python libraries.
2. Loaded the Hotel Booking dataset.
3. Explored the dataset structure using basic information and summary statistics.
4. Performed data cleaning and preprocessing.
5. Generated descriptive statistics for numerical variables.
6. Created visualizations to analyze booking cancellations, hotel types, monthly booking trends, top booking countries, ADR distribution, etc.
7. Tested initial hypotheses using the analysis results.
8. Summarized the findings and extracted key insights.

## Dataset Source -
Hotel Booking Dataset (Kaggle)
